# {{title}}

Guides explain how to do a known task, step by step: release a version,
request an access, run a team process.

## When to write a guide

- The same question came up twice in the channel
- A task has steps nobody remembers by heart
- Someone new will need to do it alone

## How to create a guide

Use "New page from template…" in this section and choose the Guide template.
Each guide says the goal, what you need first, the steps and how to check.

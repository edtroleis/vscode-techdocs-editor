# {{title}}

Os guias explicam como fazer uma tarefa conhecida, passo a passo: publicar uma
versão, pedir um acesso, rodar um processo do time.

## Quando escrever um guia

- A mesma pergunta apareceu duas vezes no canal
- Uma tarefa tem passos que ninguém lembra de cabeça
- Alguém novo vai precisar fazer isso sozinho

## Como criar um guia

Use "Nova página a partir de template…" nesta seção e escolha o template Guia.
Cada guia diz o objetivo, o que precisa antes, os passos e como conferir.

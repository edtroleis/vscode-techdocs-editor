# A barra lateral TechDocs

O ícone de livro na barra de atividades aparece nos workspaces com um `mkdocs.yml`.

| Seção | O que mostra |
|-------|--------------|
| **Documentação** | As páginas na ordem do menu do site (o `nav`), pelos títulos. Páginas fora do menu aparecem marcadas. |
| **Verificação** | O que o TechDocs precisa e está faltando ou errado, por tipo, cada item com a correção quando há uma. |
| **Publicação** | Rascunho, verificação e envio para revisão, com o painel ligado. |

# O editor visual

- Edite títulos, listas, tabelas, blocos de código e imagens como num documento.
- O arquivo continua Markdown puro: abrir e salvar sem editar não muda nada.
- Os problemas de formatação aparecem em linguagem simples, como a pipeline vai ver, com **Ajustar agora**.
- **Abrir como texto Markdown** mostra o texto ao lado, com um histórico de desfazer só.

As páginas abrem como texto por padrão. Ligue `techdocsEditor.openVisualByDefault` para abrir as páginas das docs no editor visual.

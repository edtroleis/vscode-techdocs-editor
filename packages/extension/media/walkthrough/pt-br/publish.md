# O painel de publicação

| Botão | O que acontece no GitHub |
|-------|--------------------------|
| Salvar rascunho | Uma branch e um pull request em rascunho |
| Salvar e verificar | As verificações rodam, explicadas em linguagem simples com "ver linha" |
| Enviar | Pronto para revisão, ou publicado quando não há revisão obrigatória |
| Descartar | Fecha o pull request e apaga a branch do painel |

Para todo o resto, o Git continua com o controle de versão do VS Code: o painel começa desligado.

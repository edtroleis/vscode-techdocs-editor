# The publishing panel

| Button | What happens on GitHub |
|--------|------------------------|
| Save draft | A branch and a draft pull request |
| Save and check | The checks run, explained in plain language with "show line" |
| Send | Ready for review, or published when no review is required |
| Discard | Closes the pull request and deletes the panel's branch |

Git stays with VS Code's source control for everyone else: the panel is off by default.

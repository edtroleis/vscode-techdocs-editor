# Pages from templates

| To… | Templates |
|-----|-----------|
| Learn | Tutorial, Onboarding, Golden path |
| Do a task | How-to guide, Runbook, Troubleshooting |
| Look up | Service home page, Operations and support, API reference, Wiki page |
| Understand | Architecture, ADR, Postmortem |

The file name comes from the title, the owner from `catalog-info.yaml`, and the page goes into the `nav` in the section you clicked. Your team's templates in `.techdocs/templates/` come first in the list.

# Kinds of page

**New page** creates a blank page. Type / in it, or use the TechDocs button of the toolbar, to bring the sections of a kind of page:

| To… | Templates |
|-----|-----------|
| Learn | Tutorial, Onboarding, Golden path |
| Do a task | How-to guide, Runbook, Troubleshooting |
| Look up | Service home page, Operations and support, API reference, Wiki page |
| Understand | Architecture, ADR, Postmortem |

The file name comes from the title you type the first time you save, the owner comes from `catalog-info.yaml`, and the page goes into the `nav` right after the one you selected. Your team's templates in `.techdocs/templates/` come first in the list.

# The visual editor

- Edit headings, lists, tables, code blocks and images like in a document.
- The file stays plain Markdown: opening and saving without edits changes nothing.
- Formatting problems appear in plain language, as the pipeline will see them, with **Fix automatically**.
- **Open as Markdown text** shows the text side by side, with one undo history.

Pages open as text by default. Turn on `techdocsEditor.openVisualByDefault` to open docs pages in the visual editor.
